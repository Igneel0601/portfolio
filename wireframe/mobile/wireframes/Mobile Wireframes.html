Proposed additions to globals.css
New mob-t-* classes — defined inside @media (max-width: 767.98px) alongside existing scene fixes. They do not override desktop classes — you apply both on the element and the mobile one only activates on mobile. Base rem = 14px at 390px.
globals.css — @media (max-width: 767.98px)
/* ── DO NOT override existing .t-* classes ──────────── */
/* Add NEW mob-t-* classes scoped to mobile breakpoint.
   Usage: className="t-display mob-t-display"
   Desktop → .t-display wins. Mobile → mob-t-display wins. */

@media (max-width: 767.98px) {

  /* ── headings ──────────────────────────────────────── */
  .mob-t-display {
    /* .t-display → 31.5px at 390px — too small for hero */
    font-size: clamp(2.25rem, 9.5vw, 2.75rem); /* → 36px */
  }
  .mob-t-h1 {
    font-size: clamp(1.875rem, 7.5vw, 2.25rem); /* → ~29px */
  }
  .mob-t-h2 {
    font-size: clamp(1.5rem, 5.5vw, 1.75rem); /*  → 22px */
  }
  .mob-t-h3 {
    font-size: clamp(1.25rem, 4.5vw, 1.5rem); /*  → 18px */
  }

  /* ── prose — readability bump ──────────────────────── */
  .mob-t-lead { font-size: 1.125rem;  } /* ~16px ✦ */
  .mob-t-body { font-size: 1.0625rem; } /* ~15px ✦ */
  .mob-t-sm   { font-size: 0.875rem;  } /* ~12px   */

  /* ── mono labels — no changes needed ───────────────── */
  /* .l-eyebrow, .c-md, .c-sm etc. are fine as-is       */

}
✦
.mob-t-body most important — used for case study prose, blurbs, writing post bodies. 13px is cramped on mobile; 15px reads much more comfortably. Apply as: className="t-body mob-t-body"
↑
.mob-t-display — hero headline at 31.5px feels small on 390px. 36px gives proper impact. Apply as: className="t-display mob-t-display"
–
Mono labels untouched — .l-eyebrow, .c-md etc. are already tight by design. No change.
